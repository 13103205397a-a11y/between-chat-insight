# 之间 · Between

![之间应用展示图。图中百分比为虚构演示数据](docs/banner.svg)

**仅供娱乐。** 导入两个人的文字聊天，让 [TypeSafe Jev](https://docs.typesafe.ai/introduction) 逐段阅读**全部已导入的双人消息**，观察对方是否表现出爱意、主动交流、具体关心、未来计划与明确表达。简洁的 Mac 风格界面使用衬线字体，并在结果中保留不确定性。

> 本项目是独立开源作品，不隶属于 TypeSafe。它分析的是聊天中的可见迹象，无法证明或测量任何人的真实感情，也不应替代直接沟通。请在有权处理聊天记录的前提下使用。

## 作品展示

| 步骤 | 体验 |
| --- | --- |
| 导入 | 上传常见聊天导出文件或直接粘贴；浏览器本地解析，先预览消息与参与者。 |
| 连接 | 临时填写自己的 Jev API Key，验证后开始；Key 不写入仓库或浏览器持久存储。 |
| 阅读 | Jev 分段覆盖全部已导入的双人文字消息，页面显示进度，并可停止。 |
| 判断 | 展示「爱 / 不爱」两个互补百分比、五个观察维度、完整读取条数与阅读边界。 |

展示图中的姓名、对话和百分比都是虚构示例。更多界面与计算说明见 [作品展示](docs/SHOWCASE.md)。

## 快速开始

需要 Node.js 20.3 或更新版本，以及有 Jev 访问权限的 [TypeSafe API Key](https://typesafe.ai/)。

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5173/>。在右侧「连接 JEV」输入 Key，点「验证并连接」，然后可先用示例对话试运行。Key 只保留在当前页面内存中，刷新后需重填。

也可以在本机服务端配置：

```bash
cp .env.example .env
```

在 `.env` 填入 `TYPESAFE_API_KEY=你的密钥`，重启服务后页面会自动显示已配置。`.env` 已被 Git 忽略。

生产构建：

```bash
npm run build
npm start
```

打开 <http://127.0.0.1:8787/>。服务默认只监听本机。这个仓库没有在线部署；GitHub 仓库或 GitHub Pages 无法单独运行需要服务端代理的 Jev 接口。

## 百分比怎么算

Jev 的长处是根据文本返回[结构化判断及概率](https://docs.typesafe.ai/primitives/noul)，而不是编写解释性长文。它有[单次请求的上下文上限](https://docs.typesafe.ai/models)，所以应用按顺序把完整聊天划成较短的段；超长单条消息也会完整拆段，不会只取开头、中间或末尾。每段由 Jev 判断「这段是否支持对方有恋爱爱意或持续亲密投入的迹象」及五个辅助维度。

应用按该段中**对方发言数量**加权汇总 Jev 的爱意迹象判断值，显示为「爱」。显示的「不爱」是 `100% − 爱`，并非第二次独立测量。出现反向迹象时，结论会保留「尚不明确」；任何一段调用失败，应用都不会给出部分聊天的最终结论。

这两个数是**模型对聊天迹象的娱乐性判断**，不是「对方真正爱你」的科学概率，也没有在恋爱场景做过校准。[官方文档](https://docs.typesafe.ai/models)指出 Jev 在英语上效果最好，中文等语言的效果可能不同。长聊天会触发多次 API 调用，可能产生费用；页面会显示预计段数和实际进度。

## 导入范围

支持 `.txt`、`.md`、`.csv`、`.tsv`、`.json`、`.html`、`.htm`、`.xml`，以及包含这些文件的 `.zip`。适配常见 WhatsApp 文本、Telegram JSON/HTML、LINE 制表符文本，以及含「发送者 / 内容 / 时间」字段的通用导出。普通文本可使用 `2026-08-12 09:15 张三：内容`、`[时间] 张三：内容`、`张三：内容` 等形式。

请核对导入预览。原生加密聊天数据库、截图、语音、视频及附件需要先由原应用导出或转写为可读文本。单文件最多 20 MB、总导入内容最多 25 MB、最多 100,000 条文字消息；超出时**拒绝整次导入**，不悄悄丢弃尾部消息。无法识别的文件或记录会显示提示。

## 隐私与安全

- 原文件在浏览器内解析；点击分析后，所选双人文字消息发往本机服务，再由服务发送到 TypeSafe。请阅读 [TypeSafe 数据条款](https://typesafe.ai/legal/terms)。
- 页面输入的 Key 仅存在于当前页面内存，并经本机服务传给 TypeSafe；服务端配置的 Key 仅从环境变量读取。应用不记录聊天正文、结果或 Key，也不使用第三方脚本及在线字体。
- 本机 API 限制来源和主机名，生产页面带内容安全策略。聊天请求有大小上限，ZIP 导入检查解压后大小，防止意外占用过多资源。
- 本项目尚未提供公网部署配置。若自行改为公网服务，请先加入身份验证、TLS、访问控制和额度限制；不要把服务端 Key 暴露给所有访问者。

浏览器扩展、用户自行部署的反向代理，以及 TypeSafe 本身的数据处理不受本项目控制，因此无法承诺绝对零风险。
