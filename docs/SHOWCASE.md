# 作品展示 · 之间

![之间应用展示图，图中内容均为虚构演示](banner.svg)

**项目定位**：一个私密、克制的聊天关系观察工具，面向想回看双人互动的人。它以 Jev 的结构化判断展示爱意迹象，同时明确告诉使用者：聊天记录不能读心，结果仅供娱乐。

## 从一段聊天到一份观察

1. **导入与核对**：拖入常见导出文件或粘贴文字，确认消息预览中的发送者与内容。
2. **选择视角**：标明「你是」和「想了解的人」，应用仅发送这两人的文字消息。
3. **连接 Jev**：临时输入 API Key；页面验证后可开始，也支持本机环境变量。
4. **完整阅读**：聊天按顺序分段，每条已导入的双人文字消息都会进入 Jev 的某次判断。进度可见，任务可停止。
5. **阅读结果**：并列展示「爱 / 不爱」百分比、主动交流、具体关心、未来计划、明确表达和反向迹象，附上覆盖条数与解释边界。

## 设计

冷雾灰、微蓝和白色构成安静的 Mac 风格工作台；衬线字体让聊天与结论更像一封信，而不是仪表盘。唯一的装饰性元素是两条交错的对话轨迹。导入和判断被放在同一窗口里，用户无需跳转页面。

## 示例结果

以下数字只是**虚构演示**，不来自任何真实人物或真实 Jev 调用：

| 项目 | 示例显示 |
| --- | ---: |
| 爱 · 聊天迹象 | 68% |
| 不爱 · 互补值 | 32% |
| 已读取 | 120 / 120 条双人文字消息 |

实际结果由 Jev 按聊天内容返回，再由应用按对方发言数加权。百分比不能当作对他人真实感情的客观测量。本作品不提供关系诊断或行动建议，**仅供娱乐**。
